<summary><strong>XSignOn AI-Native Security Testing & Governance Evaluation</strong></summary>

<br />

A modular, six-layer framework for adversarial testing, governance mapping, security evaluation, evidence management, and risk reporting across AI systems.

| Category        | Details                                                                                                                      |
| :-------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **Stack**       | Python, HTML, Docker and modular security-evaluation tooling                                                                 |
| **Scale**       | Six operational layers covering target abstraction through reporting and evidence                                            |

| **Impact**      | Connects technical findings to NIST AI RMF, EU AI Act concepts, organizational controls and remediation reporting            |
| **Repository**  | [View on GitHub](https://github.com/Aashu-Github/XsignOn-AI-Native-Security-Testing---Governance-Mapped-Evaluation)          |

The framework begins by modeling the target AI system and its attack surface. It then progresses through adversarial testing, classification, guardrail validation, exploit evaluation, governance crosswalking, and final evidence-based reporting.

The architecture is designed to help enterprises evaluate internal, external and third-party models through a repeatable security process while keeping testing logic, compliance mapping and reporting concerns modular.

<details>
<summary><strong>NBA Playoff Game Predictor</strong></summary>

<br />

An end-to-end machine-learning pipeline that predicts NBA playoff game outcomes using historical team-performance data and engineered matchup features.

| Category        | Details                                                                                                                        |
| :-------------- | :----------------------------------------------------------------------------------------------------------------------------- |
| **Stack**       | Python, Pandas, scikit-learn, nba_api, Matplotlib, Seaborn and Joblib                                                          |
| **Scale**       | Ten playoff seasons, more than 2,800 records and approximately 22 engineered differential features                             |
| **Performance** | Approximately 68% prediction accuracy with cross-validation and recent-season holdout testing                                  |
| **Security**    | Uses a temporal split to reduce future-data leakage; generated datasets and serialized models are excluded from source control |
| **Impact**      | Produces matchup probabilities through a CLI and generates four model-diagnostic visualizations                                |
| **Repository**  | [View on GitHub](https://github.com/Aashu-Github/nba-playoff-predictor)                                                        |

The model uses offensive rating, defensive rating, pace, effective field-goal percentage, three-point percentage, turnover rate, rest advantage and rolling plus-minus differentials.

Rather than randomly mixing historical games, the project trains on earlier seasons and evaluates against newer playoff seasons. This creates a more realistic simulation of how a model would perform on future games and reduces overly optimistic results caused by temporal leakage.

</details>
